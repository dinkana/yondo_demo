# Йондо — демо для инвестора

## Запуск

```sh
pnpm install --frozen-lockfile
pnpm dev
```

Откройте `/yondo_demo/` по адресу, который напечатает Vite. Для проверки именно сборки:

```sh
pnpm build
pnpm preview --host 127.0.0.1 --port 4318 --strictPort
```

Сценарий: [каталог с фильтрами](http://127.0.0.1:4318/yondo_demo/?days=2-3&type=caves,peaks&kids=1&max=15000) → «Иремель для всей семьи» → «Маршрут» → «Забронировать» → два взрослых и ребёнок 7 лет → демо-оплата → альбом → памятка (PDF и ICS). На панели «О демо» есть сброс для нового прогона. Никакие заявки, оплаты или фотографии не отправляются наружу.

## Проверка

При запущенном `pnpm preview`:

```sh
pnpm exec playwright install chromium
pnpm test:smoke
```

Опции: `DEMO_URL` для другого адреса, `BROWSER_CHANNEL=chrome` для установленного Chrome, `PDFTOTEXT` для автоматической проверки извлечённого кириллического текста. Скриншоты и загрузки проверки лежат в `qa-output/`. Для smoke-теста отключается service worker, внешние сетевые запросы блокируются. Тест использует desktop 1440px и mobile 375px. Это не проверка физических устройств или старого Safari.

## Графика

В `public/places/` — восемь локальных WebP-фотографий реальных мест: они используются на главной и в качестве обложек четырнадцати туров. Несколько туров одного направления могут иметь общий кадр. В `public/places/index.json` и в разделе «О демо → Фотографии маршрутов» указаны авторы, оригиналы, лицензии и изменения. Сохраняйте атрибуцию и условия лицензий при распространении. `pnpm dev` и `pnpm build` синхронизируют манифест перед запуском.

Остальные кадры галерей обозначены как иллюстрации; образцы альбома и отзывы используют локальную графику из `public/art/`. `node scripts/style-check.mjs` проверяет фильтры, возврат фокуса и оба режима движения; `node scripts/check-photo-gallery.mjs` проверяет все обложки, офлайн, управление галереей и атрибуцию. Для установленного Chrome задайте `BROWSER_CHANNEL=chrome`.

PDF использует локальный DejaVu Sans; лицензия включена рядом со шрифтом в `public/fonts/`. Погодные данные — локальные климатические примеры, карта — схематическая. В `dist/404.html` копируется входная страница для глубоких ссылок на GitHub Pages; удалённый деплой не выполнялся.
